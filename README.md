# PHOTO LAB — регламент фотографа

Демонстрационный прототип тестового задания: React + TypeScript + Tailwind CSS, статическая сборка Vite. Работает с одной главой 6; остальные роли и авторизация не реализованы.

## Запуск

Требуется Node.js 22+. Установите зависимости: `npm ci`. Локальный просмотр: `npx vite --host 127.0.0.1`. Проверки: `npm test`. Сборка: `npm run build`. Размещать содержимое `dist/` на статическом хостинге.

## Редактирование регламента

Меняйте `public/photographer.json`, затем выполняйте сборку. Поля `cards[].title`, `cards[].blocks` задают тексты; `category` связывает карточку с разделом, `source` — с пунктами исходника. `quickFacts` и `mainRule` также редактируются здесь. `originalSections` хранит исходный текст для сверки — при согласованной редактуре обновляйте соответствующую версию источника.

В тестовом исходные пункты 6.1–6.10 сохранены дословно после снятия Markdown-выделения. JSON содержит 11 карточек, четыре категории, главное правило и памятку. Пункт 6.2 разделён на обязанности и запреты. Полнотекстовый поиск работает локально, раскрывает результаты, подсвечивает совпадения, поддерживает части слов, регистр, е/ё, несколько слов (AND); для «родители» учитываются формы слова «родитель». ИИ-поиск и сервер не требуются.

## ИИ и проверка

Использован ChatGPT/Codex для структуры данных, интерфейса, кода и тестов. Источник — Markdown из задания, не исходный PDF. Семь автоматических проверок покрывают поиск, структуру меню и контраст пояснений. Проверены совпадение всех исходных абзацев, тесты поиска, TypeScript и production-сборка. В этой среде нет доступного браузерного QA; отображение и клики в живом браузере требуют проверки перед отправкой заказчику. Не заявляем, что визуальная проверка выполнена.

Приватность размещённой демонстрации определяется хостингом. Само приложение не содержит авторизации. Нельзя использовать его как закрытую базу знаний без отдельного контроля доступа.
